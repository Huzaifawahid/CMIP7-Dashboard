About
A macro-enabled Excel workbook that visualises global climate indicators across seven CMIP7 emission scenarios — from high-end warming to net-negative pathways. Charts update dynamically via pivot tables and VBA controls. Data sourced from the CMIP7 Scenario Explorer.

Van Vuuren et al. (2026) · The Scenario Model Intercomparison Project for CMIP7 · Geosci. Model Dev., 19, 2627–2656
Scenarios
Seven pathways spanning plausible futures: H HL M ML L VL LN — ranging from ~3.5 °C warming (H) to ~1.5 °C (VL/LN) above the 1850–1900 baseline by 2100.
